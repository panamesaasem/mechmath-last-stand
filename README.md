# Подготовка к началу декабря

[Журнал прогресса по трём курсам](PROGRESS.md) — основное место для отметок после занятий и ссылок на конспекты.

[Материалы по трём курсам](materials/README.md) — программы, PDF и указатель утверждений в конспекте Шафаревича.

## Курсы

- **Гайфуллин** — весенние «Дополнительные главы коммутативной алгебры», 19 вопросов. Ближайшая новая тема — кольца размерности ноль. Композиционные ряды знакомы по Атье–Макдональду и идут в повторение. [Программа и первая лекция](https://halgebra.math.msu.su/wiki/doku.php/dop_glavy_comm_algebry_25-26)
- **Горницкий** — 21 осенний вопрос по теории Ли. Первые билеты ещё не прочитаны — уточнение пользователя 8 ноября. Ближайший шаг — вопрос № 1 «Группы и подгруппы Ли. Замкнутость», затем № 2. [Экзаменационные вопросы](https://halgebra.math.msu.su/wiki/doku.php/exam_25-26) · [Конспект Тимашёва](https://teach-in.ru/file/synopsis/pdf/fundamentals-of-Lie-theory-lections-MKv1.pdf)
- **Шафаревич** — 14 лекций по алгебраической геометрии за курс. Первые темы ещё не прочитаны — уточнение пользователя 8 ноября. Ближайший шаг — § 1.1 «Аффинные многообразия» накопительного конспекта. Границы отдельных лекций сверяем отдельно. [Страница спецкурса](https://halgebra.math.msu.su/wiki/doku.php/s_k_alegrbaic_geometry_2026_2027)

## Сроки

- **7–12 ноября** — сверить уже пройденное и продолжить ближайшие темы по всем трём курсам.
- **К 26 ноября** — рабочий ориентир для первого прохода. По Шафаревичу сверять объём с доступностью материалов всех 14 лекций.
- **27–30 ноября** — резерв на устные ответы и повторное восстановление доказательств.
- **Начало декабря** — дедлайн. Точная дата пока не внесена.

Точку продолжения выбираем по подтверждённому прогрессу в журнале. Назначенная тема, дата в плане и наличие конспекта не подтверждают прохождение материала. «Знакомо» и «доказательство воспроизведено без конспекта» — разные статусы.

После занятия обновляем только затронутые строки. Если в теме несколько теорем, отмечаем отдельно, какие доказательства восстановлены и какой переход надо повторить. Новые заметки можно добавлять отдельными Markdown-файлами и связывать с соответствующей строкой журнала.
